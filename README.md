# VALOWISH

**VALOWISH** is a Valorant skin wishlist, collection, and purchase-priority manager built by **Alex Godly**.

It provides a dedicated place to browse Valorant weapon skins, organize the skins you want, track the skins you own, plan future purchases, and manage your collection.

VALOWISH is designed with a dark Valorant-inspired interface and works across desktop, tablet, and mobile devices.

---

## Features

### Browse Valorant Skins

Browse the Valorant skin catalog directly inside VALOWISH.

The Browse system includes:

- Skin artwork
- Skin names
- Weapon information
- Rarity information
- VP pricing
- Search
- Weapon filtering
- Rarity filtering
- Collection-status filtering
- Grid/list presentation
- Pagination

Browse filters can also be used to show or hide skins based on whether they are already wishlisted or owned.

---

## Wishlist

Save skins you are interested in purchasing to your Wishlist.

Wishlisted skins remain connected to the rest of VALOWISH, allowing them to be used with Browse filters and the Priority system.

---

## Priority List

The Priority List lets you organize which skins you want the most.

Skins can be ranked and reordered so you can create your own purchase plan instead of keeping an unorganized wishlist.

Priority management includes:

- Manual ranking
- Drag-and-drop ordering
- Quick move controls
- Rank positioning
- Priority tiers
- Estimated VP requirements

---

## Locker

Locker represents your owned/bought Valorant skins.

It can be used to:

- Track owned skins
- Browse your collection
- Search and filter owned skins
- Track estimated VP spent
- Separate owned skins from skins you still want

Owned skins are automatically recognized throughout VALOWISH.

---

## Collection Filtering

VALOWISH understands the relationship between your Browse catalog, Wishlist, and Locker.

Browse can be filtered to:

- Show everything
- Hide wishlisted skins
- Show only wishlisted skins
- Hide owned/bought skins
- Show only owned/bought skins
- Hide both wishlisted and owned skins
- Show only wishlisted or owned skins

This makes it easier to discover skins you have not already organized.

---

## Skin Pricing

VALOWISH includes configurable VP pricing.

Default prices can be assigned according to skin rarity, while individual skins can have their price manually overridden when necessary.

Custom skin prices take priority over default rarity pricing.

---

## VP Tracker

Track your available Valorant Points directly inside VALOWISH and compare them with the estimated cost of skins you are interested in purchasing.

---

## History

VALOWISH keeps a history of supported collection actions so changes to your skin organization can be reviewed.

Undo and redo functionality is available for supported actions.

---

## Pagination & Performance

VALOWISH is designed to handle the large Valorant skin catalog without rendering the entire database at once.

Skin collections use pagination to keep the interface responsive, particularly on mobile devices.

Navigation state is preserved where appropriate so switching between sections does not unnecessarily make you lose your place.

---

## Cloud Sync

VALOWISH supports account-based cloud synchronization using Supabase.

Supported account functionality includes:

- Sign up
- Login
- Cloud data synchronization
- Profile name
- Email management
- Password management
- Logout
- Account deletion

Each account maintains its own VALOWISH data.

---

## Local Storage

VALOWISH also uses local browser storage so application data can remain available on the current device.

Cloud synchronization is available when signed into a VALOWISH account.

---

## Import & Export

VALOWISH data can be exported as a backup and imported again when needed.

This provides an additional way to preserve or transfer your collection data.

---

## Responsive Design

VALOWISH is designed for:

- Desktop
- Laptop
- Tablet
- Mobile

The interface automatically adapts to smaller displays while preserving the main Browse, Wishlist, Priority, Locker, History, and Settings functionality.

---

## Valorant Skin Data

Skin information and artwork are retrieved from external Valorant data services.

VALOWISH uses caching and failure handling to reduce unnecessary requests and keep the application usable when external skin data is temporarily unavailable.

---

## Data

VALOWISH can store information such as:

- Wishlist
- Owned skins
- Priority rankings
- Priority tiers
- VP balance
- Skin price overrides
- Default rarity prices
- History
- Application preferences
