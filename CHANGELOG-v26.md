# VALOWISH v26 — Weapon Filters Fit Properly

**Release status:** Experimental (automated logic tests and real-Chromium desktop/mobile tests passed).

## Fixes
- **Sidearms and Rifles show every weapon.** On phones these two rows (six and five guns) ran off the edge of the filter box, while shorter classes fit. Weapon and edition chips now wrap onto extra lines, so every weapon is visible without sideways scrolling.
- **Buying plan popup filters are no longer cut off.** On desktop, the weapon chips flow together compactly, so the whole Filters & Sort panel fits inside the popup with no scrolling inside a small box. On phones, Filters & Sort opens across the full popup with a **SHOW N RESULTS** button to go back to the list.
- Slightly more compact popup header on shorter laptop screens.
