# VALOWISH v27 — Priority List → Buying Plan

**Release status:** Experimental (automated logic tests and real-Chromium desktop/mobile tests passed).

## New
- **Turn any Priority list into a buying plan.** Every Priority view (Global, a category, a weapon type such as Rifles, or a single weapon such as Vandal) has a **→ NEW BUYING PLAN** button.
- The new plan contains exactly the items in that list, in the same rank order. It is named after the list (e.g. "Priority · Vandal"), becomes the active plan, and opens in the Buying Simulator.
- The bar shows the item count and VP total before you create the plan.
- It uses the list as it's shown: active filters (search, weapon or edition chips) and a non-manual sort are applied, and the bar tells you when they are. Owned items are left out.
- Creating a plan from the same list again makes a separate copy, e.g. "Priority · Vandal (2)", and never changes an existing plan.
